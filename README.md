## What I work on

- 🪐 **Astrodynamics & celestial mechanics** — planetary ephemerides
  (JPL DE441/DE442, VSOP87/VSOP2013), eclipse and occultation computation,
  orbital dynamics, and calendrical astronomy
- 🔢 **Computational number theory** — arbitrary-precision arithmetic,
  certified computation with FLINT/Arb, integer factoring
- 👨‍🏫 **Teaching** — computer science and software engineering at the
  International Coding Academy

Most of my research code lives in private repositories while it matures;
polished projects are published here.
